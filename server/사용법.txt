========================================
서버 상시 실행 스크립트 사용법
========================================

이 폴더의 스크립트는 컴프레셔 원격 서버(run.py)를 Windows 예약 작업으로
등록해서, PC 로그인 시 자동 실행되고 죽으면 자동 재시작되도록 합니다.


[사전 조건]
- 먼저 프로젝트 최상위 폴더의 "실행.bat" 을 한 번 실행해서
  가상환경(.venv)과 패키지 설치를 끝내 두세요.


[설치]  상시실행_설치.bat  더블클릭
  - 관리자 권한을 물어보면 "예"
  - 예약 작업(CompressorRemoteServer) 등록 + 방화벽 8070 포트 허용
  - 등록 직후 서버가 바로 시작됩니다
  - 화면에 뜨는 http://<PC-IP>:8070 주소로 폰에서 접속


[제거]  상시실행_제거.bat  더블클릭
  - 예약 작업 삭제 + 실행 중인 서버 종료
  - 방화벽 규칙은 남습니다(필요하면 수동 삭제)


[상태 확인]  서버_상태확인.bat  더블클릭
  - 예약 작업 등록 여부, 8070 포트 수신 여부, 최근 로그 20줄 표시


[로그]
  server\logs\server_YYYYMMDD.log  (날짜별)


[동작 방식]
  Windows 예약 작업 "CompressorRemoteServer"
    -> serve_forever.ps1  (감시 스크립트, 창 숨김)
         -> .venv\Scripts\python.exe run.py   (실제 서버)
              죽으면 5초 후 재시작


[자주 나오는 상황]
- PC 재부팅/로그인 하면 자동으로 다시 뜹니다.
- IP가 바뀌면 폰 주소도 바꿔야 합니다. 사내 IT에 고정 IP(DHCP 예약) 요청 권장.
- "로그인 안 해도 상시 실행" 이 필요하면 예약 작업 속성에서
  "사용자의 로그온 여부에 관계없이 실행" 으로 바꾸고 계정 암호를 저장하거나,
  PC 자동 로그인을 설정하세요.
- 회사 정책상 예약 작업/방화벽 변경이 제한될 수 있으니 IT와 협의하세요.


[운영 전 체크]
- config.yaml 의 server.secret_key 를 임의의 긴 문자열로 변경
- 기본 계정 3개(admin/operator/viewer) 비밀번호 변경 또는 삭제 후 신규 생성
