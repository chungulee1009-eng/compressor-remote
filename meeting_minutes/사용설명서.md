# SAM4S AI 회의록 V1 — 사용설명서

## Executive Summary

- **녹음 버튼 → 회의 종료 → 회의록 Excel 자동 저장**까지 한 번에 처리하는 PC 프로그램 (Windows)
- 음성인식은 **PC 내부에서 처리**(faster-whisper)하여 회의 음성이 외부로 나가지 않음. AI 요약에는 회의 **텍스트만** Claude 로 전송하며, 이것도 끌 수 있음(완전 오프라인 모드)
- 회의록에서 **담당자·업무·기한을 자동 추출**해 Action Item 으로 누적 관리 → 「회의 → 업무지시 → 완료관리」 체계

```
🎙 녹음 → 음성파일(.wav) → 음성인식(PC) → 전사문 → AI 회의록(Claude) → DB 저장 → Excel / Word / PDF
                                                                     └→ Action Item 관리 · 검색
```

---

## 1. 설치 / 실행

| 단계 | 내용 |
|---|---|
| ① Python 설치 | python.org 에서 3.12 설치 (설치 시 **Add python.exe to PATH** 체크) |
| ② 실행 | **`AI회의록_실행.bat`** 더블클릭 → 최초 1회 자동 설치(5~10분) 후 실행. 실행환경(venv)은 OneDrive 동기화를 피해 `%LOCALAPPDATA%\SAM4S_MeetingMinutes\venv` 에 설치됨 |
| ③ AI 키 입력 | ⚙ 설정 탭 → Claude API 키 입력 → 저장 (키가 없으면 규칙 기반으로 동작) |
| ④ 첫 음성인식 | 음성인식 모델 자동 다운로드 (medium 약 1.5GB, 1회만) |

수동 실행:
```bash
python -m venv %LOCALAPPDATA%\SAM4S_MeetingMinutes\venv
%LOCALAPPDATA%\SAM4S_MeetingMinutes\venv\Scripts\activate
pip install -r meeting_minutes\requirements.txt
python -m meeting_minutes
```

## 2. 화면 구성

| 탭 | 기능 |
|---|---|
| 🎙 회의 녹음 | 회의명·참석자 입력 → **● 녹음 시작 / ❚❚ 일시정지 / ■ 녹음 종료** → 음성인식 결과가 **📝 인식 텍스트(TXT) 창에 실시간 표시**되고 `…_전사문.txt` 자동 저장 → (옵션) AI 회의록까지 자동 생성. **📝 텍스트만 변환** 버튼으로 TXT 까지만 만들 수도 있음. 텍스트는 직접 고친 뒤 **🤖 AI 회의록 생성** 가능(음성인식 다시 안 함). 휴대폰 녹음파일(m4a·mp3)이나 전사문(txt) 불러오기도 가능 |
| 📄 회의록 | 회의 목록 · Executive Summary · 논의/결정/문제점/미결 · Action Item. **Excel / Word / PDF 저장**, 전사문 보기, AI 재작성 |
| ✅ Action Item | 전 회의 업무 통합 관리. KPI(완료율·지연 건수), 담당자 필터, 상태 변경(미착수→진행중→완료), 기한 경과 시 **🔴 지연** 자동 표시, 현황 Excel |
| 🔍 검색 | "**어제 회의에서 김과장에게 시킨 일**", "지난주 SMT 견적" 처럼 입력 → 기간·담당자·키워드 자동 해석 |
| ⚙ 설정 | 음성인식 모델, 마이크, AI 사용 여부/분석 수준, API 키, 출력 폴더, 인식 보조 용어 |

### 자동 추출 예시

> "SMT 이전은 11월까지 검토하고, 김과장이 업체 3곳 견적을 받아주세요. 다음 주 화요일까지 부탁합니다." (10/7 수 회의)

| 담당자 | 업무 | 기한 | 상태 |
|---|---|---|---|
| 김과장 | SMT 업체 3곳 견적 확보 | 2026-10-13 (다음 주 화요일) | 미착수 |

기한 표현 인식: 오늘·내일·모레 / (이번·다음·담)주 X요일 / 이번 주까지 / N일 후 / 10/13 · 10월 13일 / 이번 달 말 · 다음 달 말 · 11월까지 · 연말

## 3. 출력물

| 파일 | 구성 |
|---|---|
| `YYYY-MM-DD_회의명_회의록.xlsx` | 시트1 회의록(Executive Summary~차기회의) / 시트2 Action Item(상태 색상) / 시트3 전사문(시각별) |
| `…_회의록.docx` | 결재·배포용 Word (맑은 고딕, 표 서식) |
| `…_회의록.pdf` | 배포용 PDF (한글 폰트 내장) |
| `…_전사문.txt` | 음성인식 원문(시각별 발언). 메모장으로 열림 |
| `Action_Item_현황_YYYY-MM-DD.xlsx` | 전 회의 미결업무 관리표 + KPI |

기본 저장 위치: `meeting_minutes\회의록_출력\` (설정에서 변경). 녹음 원본·DB·설정은 `meeting_minutes\data\` (Git 에 올라가지 않음).

## 4. 처리 시간 · 비용 (추정치, PC 사양에 따라 다름)

| 항목 | 1시간 회의 기준 |
|---|---|
| 음성인식 (CPU, medium) | 약 15~30분 · NVIDIA GPU 있으면 3~5분 |
| 음성인식 (CPU, small) | 약 5~10분 (정확도 ↓) |
| AI 회의록 (Claude) | 약 1~2분, 약 0.2달러(약 300원) 내외 |
| 규칙 기반(오프라인) | 수 초, 무료 (담당자·기한 추출 정확도는 AI 대비 낮음) |

## 5. 인식률 높이는 법

1. **USB 컨퍼런스 마이크**를 테이블 중앙에 (노트북 내장 마이크 대비 체감 효과 가장 큼)
2. 참석자란에 **이름+직급** 입력 → 음성인식 힌트 + 담당자 추출에 사용
3. 설정 → 인식 보조 용어에 제품명·고객사·모델명 등록 (예: SAM4S, 고객사명, 제품 모델명)
4. 지시할 때 "**누가 / 무엇을 / 언제까지**"를 한 문장으로 말하면 추출 정확도 ↑

## 6. 문제 해결

| 증상 | 조치 |
|---|---|
| `open() got an unexpected keyword argument 'metadata_errors'` | 음성 디코더(av) 최신 19.x 와 faster-whisper 비호환. 최신 파일로 교체 후 `python -m pip install -r meeting_minutes\requirements.txt` 재실행 (av 18 이하로 자동 조정) |
| 스마트 앱 컨트롤이 `.bat` 차단 | ZIP 속성 → 차단 해제 후 다시 압축 풀기, 또는 폴더 주소창에 `cmd` 입력 후 명령어로 실행 |
| `인식된 음성이 없습니다` | ⚙ 설정 → 마이크 선택 확인, 입력 레벨 바가 움직이는지 확인 |

## 7. 명령줄 (일괄 처리)

```bash
python -m meeting_minutes.cli 회의.m4a --title "주간 생산회의" --attendees "김과장, 박대리"
python -m meeting_minutes.cli --transcript 전사문.txt --title "SMT 이전 검토" --date 2026-10-07
python -m meeting_minutes.cli --actions      # 미결 Action Item 목록
python -m pytest meeting_minutes/tests -q    # 테스트
```

## 8. 보안

- 회의 음성: PC 밖으로 나가지 않음 (음성인식 로컬 처리)
- 회의 텍스트: AI 사용 시에만 Claude API 로 전송. 대외비 회의는 설정에서 **AI 사용 해제** → 완전 오프라인
- API 키는 이 PC 의 `meeting_minutes\data\settings.json` 에 저장됨 → 공용 PC 에서는 환경변수(`ANTHROPIC_API_KEY`) 사용 권장

## 10. 파일 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 데스크톱 화면 (Tkinter) |
| `recorder.py` | 마이크 녹음 (실시간 파일 기록 → 비정상 종료에도 녹음 보존) |
| `stt.py` | 음성인식 (faster-whisper, 한국어, 무음 구간 제거) |
| `summarizer.py` | Claude 회의록 작성 (JSON 스키마 강제), 실패 시 규칙 기반 자동 대체 |
| `rules.py` | 한국어 기한 표현·담당자(성+직급) 추출, 오프라인 회의록, 검색어 해석 |
| `storage.py` | SQLite (회의 / Action Item / 검색 / KPI) |
| `exporters.py` | Excel · Word · PDF · Action Item 현황 |
| `pipeline.py` / `cli.py` | 처리 흐름 / 명령줄 |
