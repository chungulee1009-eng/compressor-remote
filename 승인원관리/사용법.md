# 승인원 PDF → 엑셀 누적 관리대장

공유받은 승인원 PDF 를 넣으면 `승인원_관리대장.xlsx` 에 자동으로 누적 등록된다.

## 사용 방법 (Windows)

| 방법 | 동작 |
|---|---|
| **수신함 방식** | PDF 를 `승인원_수신함` 폴더에 넣고 `승인원_등록.bat` 더블클릭 → 등록 후 PDF 는 `승인원_보관/<연도>/` 로 **이동** |
| **드래그 방식** | PDF 여러 개를 `승인원_등록.bat` 아이콘 위에 끌어놓기 → 등록 후 `승인원_보관/<연도>/` 로 **복사** (원본 유지) |

- 최초 1회 실행 시 가상환경 생성 + 패키지(pdfplumber, openpyxl) 자동 설치 (Python 3.9 이상 필요)
- **엑셀 파일이 열려 있으면 저장 불가** → 닫고 다시 실행 (이 경우 PDF 는 이동되지 않음)
- 실행할 때마다 기존 대장을 `백업/` 에 자동 백업 (최근 20개 유지)

## 엑셀 구성

| 시트 | 내용 |
|---|---|
| 현황요약 | 총 건수·합격/불합격·확인필요·최근 30일 KPI, 공급업체/승인구분/적용모델/월별 집계 (COUNTIFS 수식) |
| 승인원대장 | 승인원 1건 = 1행. 발행No, 승인일자, 승인구분, 버전, 품번, 품목이름, 업체 P/N, 적용모델, 제작/공급업체, 항목별 판정(외관·치수·성능·기타), 최종판정, 결재자, 배포선, 업체 담당자/연락처, 특기사항, 원본 PDF 링크 등 37개 항목 |
| 품번별최신 | 품번별 현재 유효 버전 (실행 시 자동 재생성) |
| 검토항목 | 승인서의 검토/시험 항목별 판정 상세 |
| 승인이력 | 품번별 버전 변경 이력 (중복 자동 제거) |

- `비고` 열은 자유 기입 가능 (프로그램이 덮어쓰지 않음)
- `원본파일` 셀 클릭 → 보관 중인 PDF 바로 열림

## 중복·오류 처리

| 상황 | 처리 |
|---|---|
| 완전히 같은 PDF 재투입 | 등록 생략, 수신함 PDF 는 `승인원_수신함/중복/` 으로 이동 |
| 같은 발행No·버전인데 파일이 다름 | 등록 + `파싱상태` 에 "확인필요 / 동일 발행No·버전 재등록" 표시 |
| 일부 항목 인식 실패 | 등록 + `파싱상태` 에 누락 항목 표시 (노란색) → 수기 보완 |
| 승인서 양식 인식 불가 / 손상 PDF | 등록 안 함, `승인원_수신함/오류/` 로 이동 |

## 인식 기준

신흥정밀 `(部品)承認書` 표준 양식(1페이지 승인서, 승인이력 페이지, 시험성적서 업체정보)을 기준으로 추출한다.
텍스트가 포함된 PDF 대상이며, 스캔 이미지만 있는 PDF 는 `오류` 로 분류된다.
