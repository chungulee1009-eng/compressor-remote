승인원 관리대장 자동 등록 프로그램  (배포판 2026-10-20)
================================================================

승인원 PDF 를 넣으면 '승인원_관리대장.xlsx' 에 자동으로 누적 등록됩니다.


[1] 설치 (최초 1회)
----------------------------------------------------------------
 1. Python 설치 (이미 있으면 생략)
    - https://www.python.org/downloads/  → Download Python
    - 설치 첫 화면에서 "Add python.exe to PATH" 반드시 체크

 2. 압축 풀기 전에 '차단 해제' (중요)
    - 받은 zip 파일 마우스 우클릭 → 속성 → 맨 아래 [V] 차단 해제 → 확인
    - 그 다음 원하는 폴더에 압축 풀기
    ※ 이 단계를 건너뛰면 "스마트 앱 컨트롤이 파일을 차단했습니다" 가 뜹니다.
      이미 풀었다면 각 .bat 파일을 우클릭 → 속성 → 차단 해제

 3. '승인원_등록.bat' 더블클릭
    - 처음 한 번은 필요한 구성요소 자동 설치 (1~2분, 인터넷 필요)


[2] 사용 방법
----------------------------------------------------------------
 방법 A) 승인원 PDF 를 '승인원_수신함' 폴더에 넣고 → 승인원_등록.bat 실행
         (등록된 PDF 는 '승인원_보관\연도\' 로 이동)

 방법 B) PDF 여러 개를 승인원_등록.bat 아이콘 위로 끌어다 놓기
         (원본은 그대로 두고 보관 폴더로 복사)

 * 실행 전 엑셀(승인원_관리대장.xlsx)은 반드시 닫아주세요.
 * 결과는 화면과 엑셀 '처리로그' 시트에서 확인할 수 있습니다.


[3] 엑셀 시트 구성
----------------------------------------------------------------
 현황요약    : 총 건수, 합격/불합격, 업체별·모델별·월별 집계
 승인원대장  : 승인원 1건 = 1행 (37개 항목, 비고 열은 자유 기입)
 품번별최신  : 품번별 현재 유효 버전
 검토항목    : 검토/시험 항목별 판정
 승인이력    : 품번별 버전 변경 이력
 처리로그    : 실행할 때마다 등록·중복·실패 결과와 사유


[4] 기타
----------------------------------------------------------------
 - 승인원_재분석.bat : 프로그램 업데이트 후 기존 등록 건을 다시 판정
 - 백업 폴더         : 실행할 때마다 대장 자동 백업 (최근 20개)
 - 같은 PDF 재투입   : 등록하지 않고 '승인원_수신함\중복' 으로 이동
 - 손상/인식불가 PDF : '승인원_수신함\오류' 로 이동 (사유는 처리로그)
 - 스캔 이미지로만 된 PDF 는 인식하지 못합니다.
 - 문제 발생 시 화면 캡처와 '오류로그.txt' 를 담당자에게 전달해 주세요.
