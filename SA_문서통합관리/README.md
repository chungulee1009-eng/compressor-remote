# SA 문서 통합관리 (승인원 · 설계변경)

한 화면에서 **승인원 / 설계변경 통보서 PDF 를 올리고 [실행]** 을 누르면 문서 종류를 자동 판별해
각각의 관리대장 엑셀에 누적 정리하고, 화면에서 바로 **엑셀을 다운로드**한다.

```
 ┌───────────────────────────────────────────────┐
 │ [설계변경 관리대장  N건 누적]  [엑셀 다운로드] │
 │ [승인원 관리대장    N건 누적]  [엑셀 다운로드] │
 │ ① 문서 올리기 : PDF 끌어놓기 (섞어서 여러 개) │
 │                                       [실행]  │
 │ ② 처리 결과 : 구분 | 결과 | 파일 | 문서번호   │
 └───────────────────────────────────────────────┘
```

## 설치 / 실행 (Windows)

1. zip 우클릭 → **[압축 풀기]** → 고정 폴더(예: `D:\SA\문서통합관리`)에 둔다
   - zip 을 연 채로 실행하면 누적이 안 되므로 실행.bat 이 경고 후 중단한다
2. `실행.bat` 더블클릭 → 최초 1회 실행 환경 자동 설치 (Python 3.9 이상 필요)
3. 브라우저가 자동으로 열린다 (`http://127.0.0.1:8765`) — 검은 창을 닫으면 프로그램 종료
   - 이미 실행 중일 때 다시 실행하면 화면만 다시 연다

## 사용 방법

| 단계 | 동작 |
|---|---|
| ① 올리기 | PDF 를 끌어놓거나 클릭해서 선택 (승인원·설계변경 섞어도 됨, 여러 개 가능) |
| ② 실행 | 문서마다 종류 자동 판별 → 해당 대장에 누적 등록 → 결과 표 표시 |
| ③ 다운로드 | 상단 카드의 **[엑셀 다운로드]** → 최신 대장 파일 저장 (등록된 대장에 NEW 표시) |

| 판별 기준 (PDF 본문 텍스트) | 등록 대상 |
|---|---|
| `설계변경 통보서` | 설계변경 관리대장 |
| `承認書` / `승인서` | 승인원 관리대장 |
| 그 외 / 스캔 이미지 / 손상 | 등록 안 함 → `data\_미분류` 보관, 「인식할 수 없는 파일」 창 |

## 엑셀 파일명 (다운로드 시)

| 대장 | 파일명 | 시트 |
|---|---|---|
| 설계변경 | `2026년_SA_설계변경 관리대장_10.21.xlsx` | 현황요약 / 설계변경(YYYY) LIST / 상세대장 / BOM변경내역 / 모델별이력 |
| 승인원 | `2026년_SA_승인원 관리대장_10.21.xlsx` | 현황요약 / 승인원대장 / 품번별최신 / 검토항목 / 승인이력 / 처리로그 |

- `MM.DD` 는 **최종 저장일** — 등록할 때마다 갱신
- 엑셀의 원본파일 링크는 이 PC 의 보관 PDF 로 연결 (다운로드한 엑셀에서도 클릭하면 열림)

## 중복·오류 처리

| 상황 | 처리 |
|---|---|
| 이미 등록된 PDF 를 다시 올림 (설계변경·승인원 공통) | 등록 안 함 + **「중복 문서입니다」 에러 창** (기존 문서번호·등록일 안내) |
| 설계변경 : 같은 설변NO, 파일만 다름 | 등록 안 함 + 「중복 문서입니다」 창 → 개정본이면 기존 행 수정 |
| 승인원 : 같은 발행No·버전, 파일만 다름 | 등록 + 결과 `확인필요` (동일 발행No·버전 재등록) |
| 일부 항목 인식 실패 | 등록 + 결과 `확인필요` (엑셀 `파싱상태` 노란색) → 수기 보완 |
| 대장 저장 실패 | 「저장 오류」 창, 해당 문서 등록 취소 |

## 저장 폴더 (`data\`)

```
data\
├─ 설계변경\  2026년_SA_설계변경 관리대장_MM.DD.xlsx, 설변_보관\<연도>\, 백업\
├─ 승인원\    승인원_관리대장.xlsx, 승인원_보관\<연도>\, 백업\
└─ _미분류\   인식하지 못한 PDF
```

- 매 저장 전 대장을 `백업\` 에 자동 보관 (최근 20개)
- **기존 대장 이어쓰기** : 대장이 비어 있을 때 기존 관리대장 엑셀(.xlsx)을 화면에 올리면 자동으로 가져온다.
  원본 PDF 링크까지 쓰려면 기존 `승인원_보관` / `설변_보관` 폴더를 `data\승인원` / `data\설계변경` 에 복사.

## 구성

```
SA_문서통합관리\
├─ 실행.bat            ← 실행
├─ app.py              ← 화면 서버 (업로드 · 판별 · 다운로드)
├─ web\index.html      ← 한 화면 UI
├─ engines\ecn.py      ← 설계변경 통보서 인식·대장 (단독 실행도 가능)
├─ engines\approval.py ← 승인원 인식·대장 (단독 실행도 가능)
└─ requirements.txt
```

- 다른 PC·휴대폰에서 접속하려면 `SA_HOST=0.0.0.0` 환경변수로 실행 (사내망 전용, 보안 유의)
