# 설계변경 통보서 PDF → 엑셀 누적 관리대장

개발실에서 받은 **설계변경 통보서 PDF** 를 넣으면 관리대장 엑셀(`2026년_SA_설계변경 관리대장_10.20.xlsx`)에 자동으로 누적 등록된다.
연도별 `설계변경(YYYY)` 시트는 기존 **「신규 및 양산 설계변경 관리 현황 LIST」 양식(18개 열)** 그대로 만들어지므로 보고용으로 바로 쓸 수 있다.

## 설치 (최초 1회)

1. `설계변경_관리대장_v1.1.zip` 우클릭 → **[압축 풀기]** → 고정 폴더(예: `D:\SA\설계변경`)에 둔다
2. 그 폴더의 `설계변경_등록.bat` 실행

> ⚠ zip 파일을 연 상태에서 bat 을 바로 실행하면 Windows 가 매번 새 임시 폴더에서 실행하므로 **누적이 안 된다.**
> 이 경우 프로그램이 「실행 위치 오류」 창을 띄우고 중단한다.

## 파일명 규칙

- `<연도>년_SA_설계변경 관리대장_<MM.DD>.xlsx` — 연도는 최신 설계변경 연도, MM.DD 는 **최종 저장일**
- 등록이 있을 때마다 오늘 날짜로 파일명이 바뀌고, 이전 날짜 파일은 `백업/` 으로 옮겨진다 (같은 날은 같은 파일에 덮어씀)
- 실행 시 폴더 안에서 **가장 최근 저장된 관리대장**을 찾아 이어서 누적한다 (v1.0 의 `설계변경_관리대장.xlsx` 도 자동 승계)
- 등록 후 「완료」 창에 `이번 등록 N건 / 누적 총 M건` 과 저장 파일명이 표시된다

## 사용 방법 (Windows)

| 방법 | 동작 |
|---|---|
| **수신함 방식** | PDF 를 `설변_수신함` 폴더에 넣고 `설계변경_등록.bat` 더블클릭 → 등록 후 PDF 는 `설변_보관/<연도>/` 로 **이동** |
| **드래그 방식** | PDF 여러 개(또는 폴더)를 `설계변경_등록.bat` 아이콘 위에 끌어놓기 → 등록 후 `설변_보관/<연도>/` 로 **복사** (원본 유지) |

- 최초 1회 실행 시 가상환경 생성 + 패키지(pdfplumber, openpyxl) 자동 설치 (Python 3.9 이상 필요)
- **엑셀 파일이 열려 있으면 저장 불가** → 경고창 표시, 닫고 다시 실행 (이 경우 PDF 는 이동되지 않음)
- 실행할 때마다 기존 대장을 `백업/` 에 자동 백업 (최근 20개 유지)
- 폴더(`설변_수신함`, `설변_보관`, `백업`)는 처음 실행할 때 자동 생성

## 엑셀 구성

| 시트 | 내용 |
|---|---|
| 현황요약 | 총 건수·금년 건수·유효성검증 완료/미완료·확인필요·최근 30일·완료율 KPI, 부서×구분(HW/SW/기구), 변경사유 Pareto, 적용시기·중요도, 월별 추이 차트, 연도별 검증 현황 (COUNTIFS 수식, 실행 시 재생성) |
| 설계변경(YYYY) | 기존 LIST 양식 : 설변NO, 접수일, 부서, 작성자, 내용(현상/원인/대책/BOM 전·후), 적용모델, 구분, 적용일, 유효성검증, BOM, 라우팅, 바이어, PBA, 작/지, 버전표, 재고처리, 비고. 설변NO 번호의 연도(SA설변-**26**-0001)로 시트 자동 분류 |
| 상세대장 | 통보서 1건 = 1행. 문서번호, 제목, 발의자/연락처, 변경구분, 중요도, 변경사유, 적용시기, 단계, BOM 변경(Y/N)·변경일자, 라우팅 요청일자, SVC BULLETIN, ST 변경, 재고수량(사내/업체/발주분/기타)·처리·폐기방법, 거래선 CONFIRM, 양산검증, 현상·원인·대책 원문, 생산기술 요청사항, 배포처, 결재자, 파싱상태, 원본 PDF 링크 등 43개 항목 |
| BOM변경내역 | 별첨 BOM CHANGE INFORMATION 의 모품목·자품목·전/후·수량·실장위치·시작/종료일자 |
| 모델별이력 | 적용모델별 설계변경 이력, 모델별 최신 건 ★ 표시 (실행 시 재생성) |

- `설계변경(YYYY)` 시트의 **유효성검증·라우팅·바이어·PBA·작/지·비고** 등은 등록 후 자유 기입 (프로그램이 기존 행을 덮어쓰지 않음)
  - 유효성검증 열은 `완료 / 진행중 / 취소` 선택 목록, `완료` 는 녹색 표시 → 현황요약 완료율에 반영
  - 통보서에 근거가 없는 진행 항목(예: 라우팅 요청일 미기재, BUYER 사양서 업데이트 요청, PBA 변경)은 빈칸으로 등록 → 처리 후 기입
- 작성자(B4)는 처음 한 번 입력하면 다음 연도 시트에 자동 승계
- `설변NO` / `원본파일` 셀 클릭 → 보관 중인 PDF 바로 열림

## 자동 판정 기준

| 항목 | 기준 |
|---|---|
| 구분 (HW/SW/기구) | 제목 키워드 → 본문 키워드 → 부서 기본값 순 (MANUAL·ROM·펌웨어·BIOS → SW / PCB·PBA·부품·커넥터·라벨 → HW / BRKT·COVER·BOX·인쇄 → 기구, 근거는 상세대장 `구분근거` 열) |
| 적용일 | 기존 LIST 관례(적용월 말일) : 즉시적용 → 작성월 말일, 차기생산분 → 익월 말일, "26년 2월 부터" → 해당월 말일 |
| BOM | BOM 변경 Y → BOM 변경일자, N → `-` |
| 재고처리 | 해당없음 / 폐기 / 러닝체인지(재고수량) |
| 비고 | 적용시기 + 생산기술 요청사항 |

## 중복·오류 처리

| 상황 | 처리 |
|---|---|
| 완전히 같은 PDF 재투입 | **등록 안 함 + 「중복 PDF」 에러 메시지 창** 표시, 수신함 PDF 는 `설변_수신함/중복/` 으로 이동 |
| 같은 설변NO 가 이미 등록됨 (파일만 다름) | **등록 안 함 + 「중복 PDF」 에러 메시지 창** (기존 등록 설변NO·제목·등록일시 안내) → 개정본이면 기존 행을 직접 수정 |
| 일부 항목 인식 실패 | 등록 + `파싱상태` 에 "확인필요 / 누락: …" 표시 (노란색) → 수기 보완 |
| 통보서 양식 인식 불가 / 손상 PDF / 스캔 이미지 PDF | 등록 안 함 + 「인식 오류」 메시지 창, `설변_수신함/오류/` 로 이동 |

## 인식 기준

신흥정밀 `설계변경 통보서` 표준 양식(SHPS-QI-058-05)의 1페이지 표·체크 항목(◉ / ☑), 본문 1.현상 / 2.원인 / 3.대책,
별첨 `BOM CHANGE INFORMATION` · `APPLY MODEL` 표를 기준으로 추출한다. 체크 항목은 PDF 를 이미지로 렌더링해 선택 여부를 판별한다.
텍스트가 포함된 PDF 대상이며, 스캔 이미지만 있는 PDF 는 `오류` 로 분류된다.

## 파일 구성

```
설계변경_관리대장/
├─ 설계변경_등록.bat      ← 실행 (더블클릭 / PDF 드래그)
├─ ecn_register.py        ← 본 프로그램
├─ requirements.txt
├─ 2026년_SA_설계변경 관리대장_10.20.xlsx  ← 자동 생성 (최종 저장일 기준 파일명)
├─ 설변_수신함/ (중복/, 오류/)
├─ 설변_보관/<연도>/
└─ 백업/
```
