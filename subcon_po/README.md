# 임가공 발주서(수삽) 자동 작성기

생산계획서(SET, OPTION 생산 발주서)를 올리면 임가공 발주서 **수삽 탭**의 일자별 납품모델
(DATE · 선진행 · 신흥양산 · MODEL · BUYER · Q'TY)을 갱신한다. **SMD 탭은 수삽 탭을 참조하는 수식이라 자동 반영**.

## 실행

- Windows: `임가공발주서_실행.bat` 더블클릭 → 브라우저 <http://127.0.0.1:8071>
- 수동: `python -m subcon_po` (웹) / `python -m subcon_po 생산계획서.xlsx 임가공발주서.xlsb -o 출력폴더` (CLI)

화면: ① 생산계획서 업로드 ② 임가공 발주서 업로드(최초 1회, 이후 생략 시 마지막 발주서 재사용) ③ 발주서 작성
→ 갱신된 발주서 + 납품리스트/검토사항 다운로드.

## 적용 규칙 (`subcon_po/rules.py` 에서 수정)

| 구분 | 내용 |
|---|---|
| 제외 모델 | 모델구분 `해외OPTION`/`국내OPTION` · 모델명 `SA95`/`JK75`/`JK95`/`HCUBE`/`ZETA` 포함 · `SKE`/`SKC` 시작 |
| 납기 | 생산계획일 **D-1 영업일** (토·일·공휴일 제외, 2026~2027 공휴일·대체공휴일 내장 + 화면에서 휴무일 추가) |
| 일수량 당김 | 생산일별 수량 **+50EA 앞당김** — 예) 152EA: 2일 80 / 3일 72 → 2일 130 / 3일 22 |
| SUBLIST 미등록 | sublist 탭에 없는 모델 → 신흥양산 칸에 `SUBLIST 미등록(신흥양산)` 기입 |
| 기입 범위 | 수삽 탭 첫 구간(헤더 아래 ~ SMD버퍼 헤더 직전)의 A·B·D~G 열만. H열 이후 VLOOKUP 수식은 유지 |
| 기존 메모 | 같은 날짜·모델·바이어 행의 선진행/신흥양산 메모는 승계, 날짜 없는 수동행(예: `추가`)은 하단 보존 |

모델명은 sublist 표기(후행 공백 포함)를 그대로 써서 VLOOKUP 이 맞도록 한다.

## 저장 방식

| 환경 | 결과 |
|---|---|
| Windows + Excel (pywin32) | **.xlsb 원본 그대로** 저장 (서식·수식·매크로 100% 보존) |
| LibreOffice 설치 | .xlsb → **.xlsx** 로 저장 |
| 둘 다 없음 | 입력이 .xlsx/.xlsm 이면 openpyxl 저장, .xlsb 면 납품리스트만 제공(A~G 열 그대로 붙여넣기) |

## 검토사항 (결과 화면 + 납품리스트 파일 `검토사항` 시트)

- 일정 미정: 오더는 있으나 일자별 수량이 없는 모델 (미반영)
- 오더 ≠ 일자계획 합: 일자계획 기준 반영
- 기존 메모 중 새 일정과 매칭 안 된 행
- 제외 모델 목록과 사유
